新建地点

出口（通向其他地点；勾选「锁定」后需要事件规则解锁）
初始放置的物品（新游戏开始时地上就有，可免费拾取）
商店货物（玩家花金币购买，无限供应；勾选后填价格，0 = 免费领取）
出没的敌人（勾选已创建的敌人；指向还没建的敌人时填下面的 ID 框）

新建敌人

战利品（击杀后掉落在地上，需要玩家拾取；货币类物品会自动折算金币）
Beat 战斗配置（可选：留空 = 用引擎默认决策器）

新建 NPC

条件问候（按顺序判断，第一个满足条件的节点作为对话起点；都不满足用默认起始节点）
对话节点（每个节点是 NPC 说的一段话 + 玩家可选的选项；选项的「下一节点」为空 = 结束对话。可视化拉线请切到顶栏「画布编辑」）

新建事件规则

触发对象（按触发器类型填写；地点类留空 = 任意地点）
附加条件（可选：世界状态满足时规则才生效）
执行效果（可多个，按顺序执行）

注意：事件规则在游戏会话创建时装配，修改后对新开游戏/重置生效，进行中的游戏需重置。

游戏设置（开局配置）

初始背包（新游戏开局自带的物品；货币类物品会折算成金币）

开局配置对新开游戏/重置立即生效，不影响进行中的游戏。事件规则在「事件」页签编辑。

编辑器设置

拖动画布：鼠标右键（按住拖动任意位置都只平移画布，不会选中或移动卡片）
收起/展开属性栏的按键（点一下即收起/展开，可与拖动画布共用右键）

这些设置只保存在你当前浏览器里，修改立即生效，与游戏数据无关。
