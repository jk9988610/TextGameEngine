开发者控制台

欢迎来到开发者控制台！可用命令：
• teleport <场景ID> 传送到指定场景（tavern/forest/cave）
• add_item <物品ID> 给背包添加物品（货币类物品折算金币）
• buy [物品ID] 查看/购买当前场景商店的货物
• save 保存快照到 game_data/snapshot.json
• load 读取快照
• reset 重置游戏
